# Segurança — iFood PiP

## Versões

Utilize a versão mais recente publicada em [Releases](https://github.com/luannsr12/ifood-pip/releases). A versão 0.0.8 está em preparação no código-fonte; um ZIP local não significa que a atualização já foi publicada no GitHub ou na Chrome Web Store.

## Relatos

Relate problemas pelo [repositório do projeto](https://github.com/luannsr12/ifood-pip/issues). Informe versão, navegador, passos para reprodução e impacto observado. Para um relato sensível, solicite primeiro um canal privado, sem publicar a exploração ou os dados envolvidos.

Não inclua cookies, tokens, cabeçalhos de autenticação, códigos reais de entrega, endereços ou dados de outras pessoas em issues, logs ou capturas públicas. Os testes podem usar os dados fictícios do simulador.

## Escopo

A extensão utiliza a sessão já aberta no iFood, mantém dados do pedido e cabeçalhos em memória e armazena localmente apenas a preferência de idioma. Não há servidor do desenvolvedor nem telemetria. Consulte [PRIVACY.md](PRIVACY.md) para os detalhes.

Os ZIPs de distribuição contêm apenas arquivos de execução, ícones, catálogos e licença. Fontes de desenvolvimento, simuladores, testes, capturas e configurações locais não devem ser incluídos nesses pacotes.
